# Agent Instructions

These instructions apply to Cline and all other coding agents.

## Project

AI Ambassador is a personal AI agent for conference networking, professional research, CRM management, and personalized outreach.

## Working rules

- Prioritize a working, understandable hackathon demo.
- Follow the user's approved scope and implementation order.
- Do not add frameworks, dependencies, or application code until requested.
- Keep changes small, readable, and easy to verify; avoid unnecessary abstractions and tests.
- Preserve existing functionality and respect changes made by the user and other agents.
- Avoid simultaneous edits to the same files.
- Ask before substantial scope or architecture changes.
- Never print, expose, or commit credentials, including in commands, logs, or screenshots.
- Keep local secrets in the ignored `.env`; use blank placeholders in `.env.example`.
- Require explicit user authorization before sending outreach or other messages.
- Use lightweight verification and distinguish live integrations from simulated behavior.
- Report changes, verification results, and blockers concisely.
