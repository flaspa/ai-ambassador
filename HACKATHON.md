## Rehearsal Objectives

This repository is a private rehearsal environment for preparing the hackathon workflow.

1. Practice using Claude Code and Codex together.
2. Configure project instructions, skills, and subagents.
3. Build a small personal-agent prototype.
4. Practice integrating Cline, Composio, Parallel, and an open-source model.
5. Create a working demo that clearly shows each tool's contribution.
6. Prepare an implementation workflow suitable for the 3.5-hour hackathon.

## Development Principles

- Keep the prototype small and demonstrable.
- Prioritize a working end-to-end workflow.
- Avoid unnecessary abstractions and extensive testing.
- Use real tool integrations where feasible.
- Distinguish mocked functionality from live integrations.
- Track implementation progress in `PROGRESS.md`.
- Keep secrets and API credentials out of Git.
- Open source and share the actual hackathon submission.
